PATH COST

Not Every Route Is Equal

Routing decisions can consider the cost associated with links.

R1 2 R2 2 R6
2 + 2 = 4
THE IDEA

Lower total cost can make a route more attractive.

A routing algorithm can compare possible paths by adding their link costs. The route with the lower total cost can be selected when the algorithm is designed to minimize cost.

LINK COST + LINK COST = TOTAL PATH COST
